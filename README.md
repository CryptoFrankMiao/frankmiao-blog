# Frank's Automatic Notes

用 Open Claw 深入研读经典文章，提供完整中文翻译与个人学习笔记。
正在学习 Paul Graham 的智慧。

## 网站

https://www.frankmiao.top

## 本地开发

```bash
npm install
npm run build
```

## 部署

自动部署到 GitHub Pages 和 Cloudflare Pages。

## 文章结构

文章使用 Markdown 格式，放在 `content/articles/` 目录下。

每个文章包含：
- 中文翻译
- 英文原文
- 学习笔记

## 技术栈

- Node.js
- 纯静态 HTML/CSS/JS
- GitHub Actions 自动部署
